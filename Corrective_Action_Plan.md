
# Corrective Action Plan (CAP)

## 1. Purpose
To document corrective actions required to address identified AI governance and security control gaps.

## 2. Corrective Action Record

| Field | Details |
|---|---|
| Finding ID | AF-001 |
| Risk Category | Data Privacy |
| Identified Issue | Excessive employee access |
| Root Cause | Missing role-based restrictions |
| Risk Priority | High |
| Responsible Team | Information Security |
| Target Timeline | 30 Days |
| Current Status | Open |

## 3. Corrective Actions

1. Review existing employee access permissions.
2. Implement Role-Based Access Control (RBAC).
3. Apply least-privilege access.
4. Conduct access reviews.
5. Maintain access audit logs.

## 4. Evidence Required

- Updated access permission records.
- RBAC implementation evidence.
- Access review reports.
- Audit logs.

## 5. Remediation Verification

The AI Governance or designated control assessment team should verify implementation evidence before closing the finding.

## 6. Closure Criteria

- Corrective actions implemented.
- Evidence reviewed.
- Control effectiveness assessed.
- Residual risk reassessed.
- Finding closure formally approved.
